# Earth texture attribution

## Provenance and source distinction

The original implementation requested these files from the Three.js examples host:

- `https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg` — colour
- `https://threejs.org/examples/textures/planets/earth_normal_2048.jpg` — normal
- `https://threejs.org/examples/textures/planets/earth_specular_2048.jpg` — specular
- `https://threejs.org/examples/textures/planets/earth_clouds_1024.png` — clouds

Three.js is the example/distribution path, not the underlying texture creator. The texture library credits **Solar System Scope / INOVE**, licensed under Creative Commons Attribution 4.0 International (CC BY 4.0). The local binary assets are sourced from the corresponding Three.js example texture set.

The historical remote responses were not retained with checksums, so byte-for-byte identity with the earlier network responses has **not** been verified. The binary conversion changes storage representation only; no pixels were intentionally edited or recompressed.
